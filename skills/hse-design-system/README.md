# HSE Design System — AI Skill & Design Kit

> **ИИ-навык** · Дизайн-система НИУ ВШЭ v1.5.0

Универсальный набор правил, дизайн-токенов, официальных ассетов и линтера, обучающий ИИ-ассистентов верстать веб-страницы, промо-сайты, лендинги и интерфейсы в строгом соответствии с визуальной идентичностью и редполитикой **Национального исследовательского университета «Высшая школа экономики»**.

---

## Что умеет навык

- 🎨 **Фирменные цвета**: палитра `@hse-design/tokens` v1.5.0 (`--hse-color-brand`, `#0050CF`, `#002D6E`, акценты Dodger, Red, Orange, Green) и строгое соблюдение ролевой модели 60–30–10.
- 🔤 **Шрифты HSE Sans и HSE Slab**: подключение стилей через `fonts.css` с CDN или веб-сервера.
- ❝ **Русская типографика**: кавычки-«ёлочки» (`«...»`), вложенные „лапки“ (`„...“`), длинное тире (`—`), короткое тире в диапазонах (`–`), неразрывные пробелы `&nbsp;`.
- 🇬🇧 **Англоязычная редполитика (UK English)**: одинарные кавычки (`‘...’`), вложенные двойные (`“...”`), короткое тире в диапазонах и кампусах (`HSE University–St Petersburg`), должности и наименования по Тезаурусу ВШЭ.
- 🏛 **Официальные логотипы**: векторные SVG (12 официальных вариантов: русскоязычные с дескриптором и круглой печатью, англоязычные one line, two lines и full seal EST 1992, гербовые знаки; интерактивное демо `demo.html`).
- ♿ **Доступность (a11y) и семантика**: семантический HTML5, обязательный `alt` у картинок, ARIA-атрибуты для интерактива.
- 🔍 **Автоматический линтер**: автономный скрипт валидации верстки на соответствие дизайн-системе.

## Правила подключения ассетов (Asset Resolution)

Для гарантированного нахождения ассетов и стилей ИИ-агентом:
1. При создании проектов скопируйте папку `assets/` из состава скилла в корень проекта.
2. Подключение внешних файлов стилей **строго обязательно** (инлайновый `:root` запрещен):
   ```html
   <link rel="stylesheet" href="assets/styles/hse-tokens.css">
   <link rel="stylesheet" href="assets/styles/fonts.css">
   ```
3. Пути к ассетам рассчитываются относительно положения текущего HTML-файла:
   - Файл в корне проекта (русская версия): `src="assets/logos/hse-logo-ru_w_descriptor-blue.svg"`
   - Файл в корне проекта (английская версия): `src="assets/logos/hse-logo-en_one_line-blue.svg"`
   - Файл во вложенных папках: `src="../../assets/logos/hse-logo-ru_w_descriptor-blue.svg"`
   - Все 12 вариантов с предпросмотром собраны в [`assets/logos/demo.html`](assets/logos/demo.html).

## Линтер соответствия (CI/CD и CLI)

Скрипт написан на чистом Python 3 без сторонних зависимостей:

```bash
# Текстовый отчет в терминал
python3 scripts/check_hse_compliance.py index.html

# JSON-вывод для CI/CD-пайплайнов (GitHub Actions, GitLab CI)
python3 scripts/check_hse_compliance.py index.html --json
```

### Проверки линтера:
- 🎨 Цвета не из палитры ВШЭ (несанкционированные HEX-коды)
- 🔤 Посторонние шрифты вместо HSE Sans / HSE Slab / системных фолбэков (включая свойство `font:`)
- ❝ Прямые кавычки `"..."` вместо «ёлочек»
- ➖ Дефис вместо тире (` - ` вместо ` — `, `2025-2026` вместо `2025–2026`)
- 🖼 Теги `<img>` без атрибута `alt`
- 🔗 Отсутствие обязательных CSS-файлов (`hse-tokens.css`, `fonts.css`)

Код выхода: `0` — файл соответствует стандартам, `1` — найдены ошибки.
